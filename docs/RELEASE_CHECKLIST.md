# Release checklist

- [ ] All CI commands pass without skips.
- [ ] Model checksums match reviewed artifacts.
- [ ] Every **Requires confirmation** license entry is cleared or removed.
- [ ] Sample images have commercial-use and person/model consent records.
- [ ] Branded catalog is authorized or replaced.
- [ ] Physical device matrix is signed off.
- [ ] Camera indicator stops immediately on close/mode change.
- [ ] 10-minute sessions show no sustained memory growth.
- [ ] Accessibility assistive-technology checks pass.
- [ ] Privacy and approximation copy receives legal/product approval.
- [ ] HTTPS, MIME types, headers, compression and cache behavior pass smoke tests.
- [ ] Checkout remains disabled until a real provider is integrated.
